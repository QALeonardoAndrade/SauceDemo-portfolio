# SauceDemo — Quality Assurance Portfolio

## Sobre o projeto

Este repositório apresenta um projeto prático de Quality Assurance (QA), desenvolvido com o objetivo de aplicar conhecimentos e boas práticas de testes de software em uma aplicação web.

O projeto utiliza a plataforma SauceDemo como ambiente de testes, permitindo explorar diferentes funcionalidades e aplicar técnicas de validação funcional, identificação de cenários, elaboração de casos de teste, execução manual e automação.

A proposta é demonstrar o processo de trabalho de QA de forma estruturada, desde o entendimento das funcionalidades da aplicação até a validação dos comportamentos esperados.

## Objetivos do projeto

- Identificar e mapear cenários de teste a partir das funcionalidades da aplicação.
- Elaborar casos de teste com pré-condições, dados de entrada, passos e resultados esperados.
- Aplicar testes funcionais positivos e negativos.
- Validar regras de negócio e comportamentos da aplicação.
- Registrar resultados de execução e evidências.
- Desenvolver testes automatizados utilizando Robot Framework e Selenium.
- Aplicar controle de versão e boas práticas de organização de código com Git e GitHub.

## Escopo de testes

O projeto contempla as principais funcionalidades da aplicação:

| Funcionalidade | Cobertura |
|---|---|
| Login | Autenticação e validação de credenciais |
| Produtos | Listagem, ordenação e detalhes |
| Carrinho | Inclusão e remoção de produtos |
| Checkout | Validação de informações e finalização de compra |
| Logout | Encerramento da sessão |

Os cenários foram selecionados considerando fluxos positivos, negativos e validações importantes para o funcionamento da aplicação.

## Metodologia de trabalho

O desenvolvimento do projeto segue uma sequência estruturada de atividades:

**1. Levantamento de cenários de teste**

Identificação das situações que precisam ser validadas em cada funcionalidade, considerando diferentes possibilidades de utilização da aplicação.

**2. Documentação dos casos de teste**

Transformação dos cenários identificados em casos de teste detalhados, contendo pré-condições, massa de teste, passos de execução e resultados esperados.

**3. Organização do ambiente e versionamento**

Configuração do repositório, estruturação dos diretórios e preparação do ambiente para desenvolvimento das automações.

**4. Execução dos testes**

Realização dos testes funcionais, comparação entre resultados obtidos e esperados e registro de evidências.

**5. Automação dos testes**

Implementação de scripts automatizados para os principais fluxos da aplicação, utilizando Robot Framework e Selenium.
